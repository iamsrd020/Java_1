# Multithreading Assignments

Each assignment is intentionally kept in its own runnable Java file so it can
be opened and revised independently later:

```text
multithreading/
|-- assignments/
|   |-- Assignment01CreateThread.java
|   |-- Assignment02ThreadUsingRunnable.java
|   |-- ...
|   |-- Assignment17IdentifyDeadlock.java
|   `-- README.md
|-- theory/
|   |-- 01_MultithreadingFundamentals.md
|   |-- 02_SharingDataAndSynchronization.md
|   `-- 03_ExecutorFramework.md
`-- README.md
```
