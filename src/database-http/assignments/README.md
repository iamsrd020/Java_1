# Database and HTTP Assignments

There are two parts:

- `database/DatabaseAssignments.sql` contains executable MySQL exercises.
- `http/EmployeeApiRequests.http` contains REST endpoint examples and
  requests for IntelliJ's HTTP Client.

Read each part's README before running it. The SQL exercises create and
change tables in the selected database. The HTTP file is an API contract and
request examples; it requires an API server implementing the documented
routes to receive real responses.
